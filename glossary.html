跨境术语表

Facebook 广告、WhatsApp 营销、跨境电商专业术语速查

CPC (Cost Per Click)
单次点击成本
广告被点击一次的费用。Facebook 广告 CPC 通常 $0.3-2，热门品类竞争激烈时可达 $2-5。
CPM (Cost Per Mille)
千次展示成本
广告展示1000次的费用。Facebook CPM 通常 $8-18，旺季（Q4）可达 $20-40。
CPA (Cost Per Action)
单次转化成本
每获得一个目标行为（加购/注册/咨询等）的费用。目标 CPA 越低，广告效率越高。
CTR (Click-Through Rate)
点击率
展示转化为点击的比例。行业均值 0.9%，视频 1.46%，CTR>1.5% 为优秀，低于 0.8% 需暂停优化。
ROAS (Return on Ad Spend)
广告支出回报率
广告收入÷广告支出。例如 ROAS 3x 意味着花 $1 广告带来 $3 收入。目标 ROAS 因品类而异，标准电商 3x+，高毛利品类 1.5x 可接受。
LTV (Lifetime Value)
客户终身价值
一个客户在整个生命周期内带来的总收入。LTV 越高，越值得投入获客成本。WhatsApp 私域可显著提升 LTV（25-40%）。
BM (Business Manager)
商务管理平台
Facebook 的企业账户管理后台，用于管理广告账户、主页、像素、受众等资产。一个 BM 可管理多个广告账户和主页。
Pixel (Meta Pixel)
Meta 像素代码
安装在网站上的追踪代码，记录用户行为（浏览/加购/购买），用于优化广告投放和构建自定义受众。
CTWA (Click-to-WhatsApp)
点击跳转WhatsApp广告
Facebook/Instagram 广告格式，用户点击后直接跳转到 WhatsApp 对话。获客成本比传统广告低 5 倍，转化率高 3-5 倍。
CBO (Campaign Budget Optimization)
广告系列预算优化
Meta 自动分配广告系列内各广告组的预算给表现最好的广告组。适合多组测试，建议开 CBO 但设置最低出价。
LAL (Lookalike Audience)
相似受众
根据现有客户数据生成的相似人群包。1% LAL 最相似（CTR 高 63%），3-5% 覆盖更大、精准度下降。
A/B Test
AB测试
同时跑两个或多个变量版本，对比效果找出最优方案。Facebook 广告常见测试：素材/文案/受众/版位/出价策略。
DPA (Dynamic Product Ads)
动态产品广告
自动根据用户行为（浏览/加购/放弃）展示相关产品广告。CTR 通常 1.82%，高于普通图文广告。
Tier-1 / Tier-2 / Tier-3
国家层级
Facebook 广告的国家分类。Tier-1：美国/英国等；Tier-2：墨西哥/土耳其/巴西等；Tier-3：东南亚/非洲等。Tier-2/3 CPC 低 50-70%，适合测品。
Feed / Stories / Reels
广告版位
Facebook 广告的展示位置。Feed（信息流）最常见；Stories（故事）沉浸感强；Reels（短视频）增长最快，CTR 可达 2.3%。
Conversion API (CAPI)
转化API
服务端事件追踪，比 Pixel 更准确，不受 iOS 14.5+ ATT 政策影响。开启后广告学习阶段更快，优化更精准。
Learning Phase
学习阶段
新广告发布后 7 天内，Meta 算法在积累数据优化投放。学习阶段尽量不要改设置，期间成本波动是正常的。
Cold Audience / Warm Audience
冷受众 / 温受众
冷受众：从未接触过品牌的新用户，需要教育型内容。温受众：已有互动/加购的用户，可用促销和紧迫感内容。
Retargeting
再营销
针对已访问过你网站或与广告有过互动的用户投放广告。再营销受众转化率通常是冷受众的 5-10 倍。
SKU (Stock Keeping Unit)
库存单位
产品的唯一标识码，用于库存管理和订单追踪。每个 SKU 对应一个具体的产品规格（颜色/尺寸等）。
MOQ (Minimum Order Quantity)
最小起订量
供应商或批发商要求的最低订单数量。B2B 批发常见 MOQ $100-500，是区分零售和批发的重要指标。
OEM / ODM
贴牌 / 定制生产
OEM：代工生产，品牌方提供设计，厂家按要求生产。ODM：厂家提供设计，品牌方直接使用。
SKU潜逃 (SKU Hiding)
隐性违规
广告账户通过技术手段隐藏真实销售产品，绕过 Meta 审核。风险极高，一旦被检测账户永久封禁。
Cloaking / 斗篷
伪装技术
向 Meta 审核机器人展示合规页面，向真实用户展示真实销售页面的技术。严重违规，账户封禁风险极高。
三不限户
不限域名/主页/品类
无任何限制的广告账户，适合敏感品类。但成本高（$500-2000/月），且需要稳定的账户来源渠道。
白牌户 / 域名户
域名验证通过的广告账户
通过域名备案验证的广告账户，通过率可达 98%，适合需要快速测试多个品类的卖家。
WABA (WhatsApp Business Account)
WhatsApp企业账号
通过 WhatsApp Business Platform 创建的企业账号，用于发送商务消息模板（需审核）和管理客户对话。
Message Template
消息模板
WhatsApp Business API 的预审消息格式，用于主动联系客户（订单通知/物流提醒/营销消息）。内容固定模板，违规会被封号。
